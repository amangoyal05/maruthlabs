Long-document understanding

Build on the API

An OpenAI-compatible endpoint, so existing code works by changing a base URL and a key. Free while Madhuram-v0.6 is in preview, with streaming and the usual sampling controls.

Custom engagement

Task-specific finetuning

At this size a model is cheap and quick to specialise. We finetune Madhuram on your labels for classification, extraction, or routing, and hand back a model that fits your task rather than a general one that approximates it.
